CURRENT PRODUCT DIRECTION

Fixer is a local-first repository analysis and AI-context preparation tool.
It scans a local repository deterministically, reports a small set of explainable
measurements, and generates a compact AI-readable repository packet that the user
can manually provide to any coding agent.

Fixer is not an AI coding agent, code converter, migration tool, or replacement
for Codex, Claude Code, Cursor, or similar products. It does not observe external
agent activity or actual token usage.

CURRENT APPLICATION FLOW

1. User chooses a local repository folder through the native Tauri picker.
2. React invokes the Rust scan_repo command.
3. Rust walks readable local files and excludes common dependency/build noise.
4. Files are deterministically classified by repository-context role.
5. Fixer calculates verification, privacy, import-graph, size, and token signals.
6. Fixer calculates deterministic expense/readiness scores.
7. Fixer generates a compact RepoDigest from scanner facts.
8. The report is saved to local SQLite and displayed in React.
9. The user can manually rescan or export the complete report as JSON.

DETERMINISTIC LIMITS

- Fixer cannot observe actual tokens or spending from external coding agents.
- Fixer cannot predict agent success, retries, or task-specific context needs.
- Token counts depend on the selected tokenizer/encoding.
- Semantic duplication and dead code cannot be claimed from the current analyzer.
- Exact duplicates can be added later through content hashing.
- Packet freshness can be supported once manifests are stored and compared.
